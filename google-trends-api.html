A Google Trends "API" that actually returns data

Google Trends has no official API, and most quick scripts return empty because of a session handshake. These handle it.

Free: the command-line tool

No signup, no key — run it with npx:

npx gtrends-cli "bitcoin" US "today 3-m"

View on GitHubnpm

At scale: the hosted version

For bulk jobs, scheduling, and reliability (rotating proxies, retries), the hosted version takes any list of keywords in, interest-over-time points as clean JSON out, pay only for keywords that return data.

Open on Apify

Common uses

market and niche research, SEO seasonality, retail-attention signals on tickers.

Honest limitations

Values are Google’s relative 0–100 index per keyword, not absolute search volumes.
